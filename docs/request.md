各位同学们好！本次结课项目的主题是「基于 Web 的智能巡检机器人二维仿真系统」。大家将搭建一个可以在浏览器中操作的巡检场景，让访客查看二维地图、手动控制机器人，并观察机器人状态的变化。

项目可以个人完成，也可以由 2–5 人组队完成。技术方案由个人或小组自行选择，使用普通电脑即可开展。
- 基础版是共同的最低目标，包括 Web 界面、后端 API、二维地图、机器人手动控制与状态反馈，以及 Git 版本管理、基础 CI 和 Docker 部署。
- 标准版在完成基础版后按专项方向选做。自动巡检、路径规划、虚拟传感器和异常处理都是可选任务，路径规划算法自选。个人和人数较少的小组完成所选方向的任务即可，组队时按实际分工验收。
- 进阶版可按兴趣自由拓展，例如加入 AI 模型、Agent 或更复杂的机器人控制功能。
项目模板仓库为 https://github.com/Yhimhas/patrol-sim 仓库docs/ 中的需求、分工、架构和运行说明是参考材料。大家可以自行安排文件名、章节和表格，也可以合并成一份文档，只要把实际功能、运行方式、项目架构和成员贡献写清楚即可。

结课时请提交可访问的代码仓库、README、运行说明、项目架构图、成果展示材料，以及个人完成内容或小组分工。根 README 是写给项目访客看的，请简要介绍你们的结课作品、项目能做什么。部署可操作的在线演示后，请把实际访问地址放在 README 开头，方便访客直接体验。
